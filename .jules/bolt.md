## 2026-08-11 - SQLite WAL Mode & Query Indexing
**Learning:** SQLite in Android / embedded Python applications performs frequent disk syncs during writes and sequential scans for unbounded queries like financial reports or terminal session lookups. Enabling WAL mode (`PRAGMA journal_mode = WAL;`) and setting `PRAGMA synchronous = NORMAL;` drastically reduces disk I/O latency while allowing concurrent read access. Adding indexes on `transactions(created_at)`, `sessions(terminal_id, start_time)`, and `connection_logs(terminal_name, logout_time)` speeds up report generation and session status polling.
**Action:** Always enable WAL mode for SQLite databases used in Flask apps running in embedded/mobile environments like Android/Termux, and create compound or targeted indexes for date range queries and foreign key joins.
